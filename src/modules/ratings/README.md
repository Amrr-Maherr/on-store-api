# ratings

## Description
This module is responsible for managing ratings operations inside the application. It includes the model, controller, service, validation, and routes layers.

## Core files
- model.ts
- controller.ts
- service.ts
- validation.ts
- routes.ts
- index.ts

## Routes
- GET /api/v1/ratings
- POST /api/v1/ratings
- PATCH /api/v1/ratings/:id
- DELETE /api/v1/ratings/:id
