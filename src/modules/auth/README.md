# auth

## Description

This module is responsible for authentication operations inside the application. It includes the model, controller, service, validation, and routes layers.

## Core files

- model.ts
- controller.ts
- service.ts
- validation.ts
- routes.ts
- index.ts

## Routes

- POST /api/v1/auth/register
- POST /api/v1/auth/login
- POST /api/v1/auth/logout
