# brands

## Description

This module is responsible for managing brands operations inside the application. It includes the model, controller, service, validation, and routes layers.

## Core files

- model.ts
- controller.ts
- service.ts
- validation.ts
- routes.ts
- index.ts

## Routes

- GET /api/v1/brands
- GET /api/v1/brands/:id
- POST /api/v1/brands
- PATCH /api/v1/brands/:id
- DELETE /api/v1/brands/:id
