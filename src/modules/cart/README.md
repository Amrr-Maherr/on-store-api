# cart

## Description

This module is responsible for managing cart operations inside the application. It includes the model, controller, service, validation, and routes layers.

## Core files

- model.ts
- controller.ts
- service.ts
- validation.ts
- routes.ts
- index.ts

## Routes

- GET /api/v1/cart
- POST /api/v1/cart
- PATCH /api/v1/cart/:id
- DELETE /api/v1/cart/:id
