# wishlist

## Description
This module is responsible for managing wishlist operations inside the application. It includes the model, controller, service, validation, and routes layers.

## Core files
- model.ts
- controller.ts
- service.ts
- validation.ts
- routes.ts
- index.ts

## Routes
- GET /api/v1/wishlist
- POST /api/v1/wishlist
- PATCH /api/v1/wishlist/:id
- DELETE /api/v1/wishlist/:id
