# coupons

## Description
This module is responsible for managing coupons operations inside the application. It includes the model, controller, service, validation, and routes layers.

## Core files
- model.ts
- controller.ts
- service.ts
- validation.ts
- routes.ts
- index.ts

## Routes
- GET /api/v1/coupons
- POST /api/v1/coupons
- PATCH /api/v1/coupons/:id
- DELETE /api/v1/coupons/:id
