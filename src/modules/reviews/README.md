# reviews

## Description

This module is responsible for managing reviews operations inside the application. It includes the model, controller, service, validation, and routes layers.

## Core files

- model.ts
- controller.ts
- service.ts
- validation.ts
- routes.ts
- index.ts

## Routes

- GET /api/v1/reviews
- POST /api/v1/reviews
- PATCH /api/v1/reviews/:id
- DELETE /api/v1/reviews/:id
